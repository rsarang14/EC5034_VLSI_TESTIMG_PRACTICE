LAB 5 - ALU + ACCUMULATOR CONFORMAL LEC

Tasks 1-9 use the same 4-bit ALU + accumulator DUT. For each task:
1. cd into TaskN.
2. Run: make bug
3. Record mapped/unmapped/NEQ/abort information.
4. Use diagnose -noneq and report test vector -noneq where appropriate.
5. Inspect the schematic and identify the cause.
6. Correct revised_netlist.v.
7. Re-run LEC and obtain equivalence.


Do not modify the golden RTL.

Default library: slow_vdd1v0_basiccells.v. 

Recommended order: Tasks 1-9
